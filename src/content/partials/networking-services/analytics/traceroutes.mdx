Magic {props.productName} customers can run traceroutes to understand the hop by hop Internet path and latencies from Cloudflare's network to their own network.

To run a [traceroute](https://www.cloudflare.com/learning/network-layer/what-is-mtr/) from a specific [Cloudflare data center](https://www.cloudflare.com/network/) to your network:

1. Log in to the [Cloudflare dashboard](https://dash.cloudflare.com/) and select your account.
2. Go to **Magic {props.productName}** > **Tunnel Health**.
3. Expand a [Magic connector](https://developers.cloudflare.com/cloudflare-wan/on-ramps/), and find the [Cloudflare data center](https://www.cloudflare.com/network/) where the traceroute will be run from.
4. Select **Run traceroute**.

You can access detailed data from the traceroute, including:

- [Traceroute](https://www.cloudflare.com/learning/network-layer/what-is-mtr/) hops
- Radar details for the target IP: AS, geolocation, URL scans
- Average, minimum, maximum, and standard deviation for network latency
- Packet loss percentage and packet count

## Troubleshooting traceroutes

Traceroutes cannot be run against private IPs. If the existing target is a private IP, navigate to your account home > Networking > Connectors to specify a customer endpoint for your [connector](https://developers.cloudflare.com/cloudflare-wan/on-ramps/) type.
