After adding sites to your Magic WAN configuration, the network overview provides a summary of site connectivity and related traffic analytics. This serves as a great entrypoint to triage Magic WAN alerts, troubleshoot connectivity issues, or update site and connector configurations.

Refer to [Set up a site](/cloudflare-wan/configuration/common-settings/sites/) for more information.
